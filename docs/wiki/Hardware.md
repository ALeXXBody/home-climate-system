# Hardware

## Supported

- DIYLess **Master** OpenTherm Shield
- ESP8266 D1 mini (stacks on shield)
- LOLIN / Wemos S2 mini (GPIO4/5 OT)
- LOLIN C3 mini v2.1 (GPIO7/6)
- ESP32 D1 mini · ESP32-S3-Zero (jumpers as needed)

## Wiring

See [docs/hardware.md](https://github.com/ALeXXBody/home-climate-system/blob/main/docs/hardware.md) for pin maps and OT bus notes.

## Not in scope

Room TRVs and wall sensors attach to Home Assistant / Zigbee / etc. HCC commands them; HCS only drives the boiler.

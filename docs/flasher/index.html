Home Climate System — firmware flasher (v0.3.0)

Flashes over USB directly from this page. Works in Chrome / Edge on desktop (Web Serial). No drivers needed on Linux/macOS; Windows 10/11 usually auto-installs.

ESP8266 — D1 mini (stacked on DIYLess Master shield)

ESP32-C3 — LOLIN C3 mini v2.1 (stacked on DIYLess Master shield)

Steps: connect the board by USB → click Install → pick the serial port (ttyUSB…/cu.usbserial…/COM…) → confirm erase.

Tips:
  • If the port is missing or install fails at "Connecting": hold the BOOT button while plugging in, then retry (C3/S2/S3 native USB).
  • Close any serial monitor using the port first.
  • After flashing the LED blinks and the device starts access point HCS-Setup (password homeclimate) — join it to configure WiFi/MQTT, see flash guide.
  • This erases settings when you tick "erase device" — plan to re-run setup.
